# Техническое задание

**Плагин:** Radix Hover
**Среда разработки:** Visual Studio Code, API ≥ 1.85
**Язык реализации:** TypeScript
**Автор:** Никишин Глеб Олегович, M3104

## 1. Назначение

Плагин показывает при наведении курсора на числовой литерал его значение
сразу во всех добавленных системах счисления и позволяет заменить литерал на
запись в любой из них одним кликом по ссылке в подсказке.

## 2. Функциональные требования

1. Распознавание числового литерала под курсором:
   * со стандартным префиксом (`0b`, `0o`, `0x`) — система счисления
     определяется префиксом;
   * обычная десятичная запись без префикса;
   * десятичная на вид запись со служебным комментарием `// radix: N` справа
     на той же строке — интерпретируется как запись в системе с основанием
     N, если все её цифры допустимы для этого основания.
2. Отсечение ложных срабатываний: обычные идентификаторы кода (переменные,
   имена функций) подсказку не вызывают.
3. Подсказка показывает таблицу «система счисления → значение» по всем
   системам из реестра плагина; название системы — кликабельная ссылка
   замены.
4. Клик по ссылке заменяет литерал в коде на соответствующую запись и:
   * убирает комментарий `// radix: N`, если новая запись самодостаточна
     (есть префикс или это десятичная запись);
   * добавляет либо обновляет комментарий, если новая система — не
     стандартная и без префикса.
5. Подсказка после замены обновляется автоматически.
6. Команды `Add new radix` / `Remove new radix` — добавление и удаление
   пользовательской системы счисления (основание от 2 до 36) в реестр,
   доступные через палитру команд.

## 3. Нефункциональные требования

1. Перевод чисел между системами счисления реализован самостоятельно, 
   без использования встроенного `Number.prototype.toString`.
2. Реестр систем счисления реализован как структура данных — отсортированный
   массив с двоичным поиском (O(log n) на поиск и вставку), а не как
   неупорядоченный список.
3. Ядро распознавания и перевода чисел (`numberLiteral.ts`) не зависит от
   API VS Code.

## 4. Ограничения

1. Поддерживаются только целые числа.
2. Комментарий `// radix: N` применим только к литералам, целиком состоящим
   из десятичных цифр — записи с буквами без стандартного префикса не
   распознаются.
3. Разбор построчный, без учёта синтаксиса конкретного языка
   программирования.
