# Radix Hover

**Автор:** Никишин Глеб Олегович, группа M3104
**Дисциплина:** Инструментальные средства разработки ПО, лабораторная работа №3
**IDE:** Visual Studio Code (API ≥ 1.85), язык реализации — TypeScript

## Описание

Radix Hover — плагин для VS Code, который при наведении курсора на числовой
литерал показывает его значение сразу во всех известных плагину системах
счисления и позволяет заменить литерал на запись в любой из них одним
кликом.

## Возможности

### Распознавание чисел

Подсказка появляется при наведении на:

* **Литералы со стандартным префиксом** — `0b1010` (двоичный), `0o17`
  (восьмеричный), `0xFF` (шестнадцатеричный). Система счисления определяется
  однозначно по префиксу.
* **Обычные десятичные литералы** — `13`. По умолчанию считаются записанными
  в десятичной системе.
* **Десятичные на вид литералы со служебным комментарием** — `101 // radix: 5`
  интерпретируется как запись числа `101` в системе с основанием 5 (а не как
  число сто один), если все его цифры действительно допустимы для указанного
  основания.

Идентификаторы кода (переменные, имена функций) числами не считаются и
подсказку не вызывают.

### Подсказка при наведении

Показывает таблицу «система счисления → значение» по всем системам,
зарегистрированным в реестре плагина (по умолчанию — двоичная, восьмеричная,
десятичная, шестнадцатеричная). Название каждой системы в таблице — это
кликабельная ссылка: клик заменяет литерал в коде на запись числа в этой
системе.

### Замена литерала с синхронизацией комментария

При замене литерала плагин сам решает, что делать со служебным комментарием
`// radix: N`:

* если новая запись понятна сама по себе (есть стандартный префикс, либо это
  обычная десятичная запись) — комментарий убирается;
* если новая запись — в добавленной пользователем нестандартной системе без
  префикса — комментарий добавляется или обновляется на актуальное основание.

Подсказка после замены обновляется автоматически, без повторного наведения.

### Команды

| Команда | Назначение |
| --- | --- |
| `Add new radix` | Добавить в реестр свою систему счисления (основание от 2 до 36) |
| `Remove radix` | Удалить систему счисления из реестра |

Обе доступны через палитру команд (`Ctrl+Shift+P`). Добавленные системы сразу
появляются в таблице подсказки, встают на своё место по возрастанию основания
и получают собственную ссылку для замены.

## Установка и запуск

Требуется Node.js 18+ и VS Code 1.85+.

```bash
git clone <ссылка на репозиторий>
cd radix-hover
npm install
npm run compile
```

Запуск в режиме отладки: открыть папку проекта в VS Code, нажать `F5` —
откроется окно Extension Development Host с подключённым плагином.
